Needed for Update news, Fact check, Week in review, saving collection settings and syncing your Read and Favourites between devices.

Key
  1. Open github.com/settings/personal-access-tokens/new and name it News Digest app.
  2. Set Expiration to the longest option you are comfortable with.
  3. Under Repository access choose Only select repositories, then pick NewsSummarizer.
  4. Under Permissions, Repository permissions, set Contents to Read and write, and Actions to Read and write.
  5. Click Generate token, copy it and paste it above.
