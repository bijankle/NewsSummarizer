GitHub key

Saving collection settings, and the Update news now button, need a free GitHub key for this project. To make one:

  1. Open github.com/settings/personal-access-tokens/new and give it a name such as News Digest app.
  2. Set Expiration to the longest option you are comfortable with.
  3. Under Repository access choose Only select repositories, then pick NewsSummarizer.
  4. Under Permissions, Repository permissions, set Contents to Read and write, and Actions to Read and write.
  5. Click Generate token, copy it and paste it into the box above.

Everything else (search words, outlets, blocked sites, AI model) lives in the full settings file.
